# thavan-apps

Mini-apps e guias interativos da Casita (Thavan), pensados para abrir rápido no celular e no computador.

## Aplicativos

- [**Finanças da Casita · Guia Rápido**](./financas/) — cartilha interativa para classificar lançamentos, conferir o acerto do mês e rodar o rito semanal sem complicação.
